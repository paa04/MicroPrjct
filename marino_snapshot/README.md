# Пространственная конкуренция фитнес-клубов Марьино

Зафиксированный снимок проекта по Марьино (27.11.2026), до расширения на Москву. Сетевой Хотеллинг — основная модель; коммерческие здания OSM — прозрачное ограничение стратегий. Детерминированный выбор с фиксированными тарифами и Logit без перегруженности — только проверка чувствительности. Никакого обучения, геоэмбеддингов, эндогенного ценообразования или калибровки параметров.

## Запуск
Python 3.10+; из корня проекта:

```bash
pip install -r requirements.txt
python run_all.py
```

Команда последовательно запускает `run.py`, `insights/analyze.py .` и `insights/plot.py`, пересоздаёт CSV, карты и оба файла проверок из комплектных данных; интернет не нужен. Все идентификаторы `site` — **нулевой номер строки** `data/candidates.csv`, а не `grid_index`. Для PDF: `cd report; xelatex Marino_Report.tex; xelatex Marino_Report.tex`. В Overleaf загрузите папку проекта, выберите XeLaTeX, главным файлом укажите `report/Marino_Report.tex`. Отчёт содержит численные результаты текущего прогона; при изменении параметров его таблицы нужно обновить.

## Что именно сделано
- 920 контуров внутри границы из адресного архива OSM; 103 с тегами `retail/commercial/sports_centre` (последних в этой выборке нет). Геометрия проецируется в EPSG:32637. Отбор по площади контура ≥500/1100/1500 м². Репрезентативная внутренняя точка привязывается к ближайшему допустимому узлу сетки, не далее 200 м. Основной сценарий исключает контуры на расстоянии ≤30 м от известного клуба и контур женского клуба «Мисс Фитнес» (OSM 46679150); отдельно проверено включение этих зданий. Это прокси, не реестр свободных помещений. Неполные теги и адресный отбор могут исключить подходящие здания.
- 365 жилых объектов, 23 клуба 18 сетей, 3894 географические точки, масштаб населения 273463 (вторичная публикация оценки на 01.01.2025). Основные веса — по числу квартир из справочника «Домпаспорт»: 358 адресных записей, 361 из 365 полигонов сопоставлены, 4 импутированы; без двойного счёта повторяющихся адресов. Старые веса по площади × этажности — контроль. Внешние клубы фиксированы, учитывается только потенциальный спрос жителей Марьино. Наблюдаемые доли продаж отсутствуют. Все доли и HHI/CR3 модельные.
- Оптимумы всех сетей на 3 определениях рынка, maximin DDX, отклонения 9 клубов и максимумы по 8 сетям, локальная доступность в 5–20 минутах. Полный перебор двухфирменной игры DDX–Spirit на каждом ограниченном наборе; две прежние конфигурации полной сетки проверены по всем отклонениям и не являются равновесиями с новыми весами (не новый исчерпывающий поиск на полной сетке).
- Неоднородные цены: опубликованные тарифы (часть — цены «от»), пропуски заменены 2000/2500/3000 ₽. Цена DDX 1900 ₽ — нижняя рекламируемая граница. Стоимость минуты расстояния в месячной полезности 50/100/200 ₽; для Logit полураспад 5/10/20 минут. Выбор среди клубов условно на покупке абонемента; общий рынок фиксирован. Эти параметры не оценены по поведению клиентов. Модель не учитывает вместимость, перегруженность и качество.
- Экономика входа: сценарные доля покупателей 5%, маржа 900 ₽, прочие расходы 300 тыс. ₽/мес., площадь 1300 м². Дополнительно варьируются 3/5/8/10/12/16,5% (московский ориентир FitnessData не равен доле жителей Марьино), 600/900/1200 ₽, 0/300/600 тыс. ₽. Аренда, CAPEX, налоги и реальная маржа не известны для действующих сетей. Пять архивных объявлений не проходят требование DDX по площади, шестое ранее снято, вновь обнаружено в индексе, доступность не подтверждена. Новое предложение 1297 м² в том же ТЦ, где работает DDX, не считается независимым входом. Нет подтверждённого доступного объекта. Новая оценка без перегруженности не обязана совпадать с прежней.

## Эмпирическое уточнение
- `housing_registry.csv` и `results/housing_match.csv` — первичные для расчёта числа квартир из вторичного справочника и их адресное сопоставление. `housing_summary.json`, `population_comparison.csv`, `loo.csv`, `club_stress.csv` — новые проверки.
- `data/financial_context.csv`, `property_review.csv`, `club_review.csv` — проверенные дополнительные ориентиры и ограничения; не полный актуальный реестр. `finance_thresholds.csv`, `break_even_penetration.csv` — сценарные пороги.
- `docs/survey.md` — анкета, не проведённый опрос.

## Файлы
- `data/`: геоданные, матрицы расстояний, реестр, тарифы, объявления; источники и лицензия. Полигональный адресный слой из `marino_project (2).zip/cache/address_buildings.geojson` (путь внутри архива: `marino_project/cache/address_buildings.geojson`); остальные данные из предыдущего финального LaTeX-проекта. Новой выгрузки OSM нет. Проверены отдельные тарифы, объявления и клубы; полный новый реестр недоступен.
- `results/buildings.csv`, `commercial_buildings.geojson`, `strategy_sets.csv`: проверяемый отбор зданий, адреса, OSM ID и привязки.
- `market.csv`, `overlap.csv`, `optima.csv`, `robust.csv`: концентрация, локальная доступность, размещение и каннибализация.
- `relocation.csv`, `network_regret.csv`, `regret_summary.csv`: отклонения. Сохранение текущего положения всегда разрешено; перемещение только одного клуба сети.
- `equilibria.csv`, `game_summary.csv`, `game_payoffs.csv`, `unrestricted_verified.csv`: равновесия и выигрыши.
- `demand_sensitivity.csv`, `comparison_surfaces.csv`, `comparison_equilibria.csv`, `comparison_game_summary.csv`: различия трёх моделей спроса. Logit — не обученная модель.
- `property_economics.csv`, `rent_sensitivity.csv`: сценарный финансовый анализ. Для неподходящих по площади объектов расчет лишь диагностический, без учёта вместимости.
- `report/`: единый отчёт PDF и исходник LaTeX; `figures/`: воспроизводимые графики; `docs/`: исходное задание, формализация и происхождение данных.

Главный вывод: географические ограничения уменьшают средний сетевой regret с 7,21 до 4,91 п.п., но максимум остаётся 11,90 п.п.; у Spirit и Территории фитнеса на основном множестве regret равен нулю. Робастный оптимум базового Хотеллинга — Новомарьинская ул., 20, однако доступность помещения неизвестна. При иных предпосылках о ценах и выборе перспективные точки и финансовые пороги меняются. Рекомендация — искать помещение на востоке, не утверждать выгодность или невыгодность открытия без проверки конкретного договора и спроса.
